# Ultimate Macro v1.3.5

## Fixed

- Fixed Settings hotkey status messages so TDS Keybinds and Recording Hotkeys update only their own status text
- Fixed DJ track switching intermittently clicking unrelated red/green/purple UI by restricting detection to the tower panel and adding one bounded confirmation click when Roblox swallows the first input
- Fixed placement failure classification so insufficient cash keeps the exact recorded coordinates, while only an explicit "cannot place here" response is allowed to move to an offset
- Fixed unresolved placement retries drifting towers away from older strategy coordinates; unknown failures now retry the same spot and fail safely instead of guessing a new position
- Hardened raw input recording startup and crash autosave so a failed InputHook reports the actual error and in-progress clicks/keys are preserved before save/reload/exit
- Removed the debug overlay capture-exclusion flag (`WDA_EXCLUDEFROMCAPTURE`) because it can interfere with external screen recorders/Game Bar; the overlay is still ignored by macro OCR through explicit hit filtering
- Fixed a placement bug
- Fixed an unfocus click bug
- Fixed an issue where some modes in the list weren't being clicked
- Fixed a slight Timescale issue

- Fixed a major bug where AHK message boxes inside bridge callbacks could completely freeze the macro UI in the editor. Errors now use in-app notifications, and confirmations use proper in-app dialogs
- Fixed table column offsets in the editor that caused X/Y values, movement, undo, and redo to affect the wrong cells
- Fixed footprint rings not rendering correctly in the editor
- Fixed the macro window being unable to move in the editor
- Fixed the minimize button not working in the editor
- Fixed maximize/restore behavior in the editor, including titlebar double-click
- Fixed replay state carrying over between strategies in the editor
- Fixed calibration marks being added to the wrong table in the editor
- Fixed blank X/Y values incorrectly moving towers to 0,0 in the editor
- Fixed replay status text being constantly overwritten in the editor
- Fixed macro paths being stored incorrectly in the editor
- Fixed disabled buttons still showing active accent colors in the editor
- Fixed the placements table overflowing into the status bar in the editor
- Fixed boolean values being incorrectly read from WebView2
- Fixed a major placement bug where failed positions could be tried again, causing the macro to get stuck
- Fixed placement retries dropping the tower before trying the next position
- Fixed Timescale sometimes failing to activate correctly
- Fixed Timescale sometimes activating and then leaving the game, wasting the run
- Fixed Timescale failing when the confirmation window took longer to appear
- Fixed tower detection missing the bottom of the screen at 1920x1080
- Fixed clicks being sent to the wrong position when Roblox was closed or minimized at the wrong time
- Fixed Strategy Rotation incorrectly enabling Auto Equip Towers
- Fixed the Discord bot screenshot command capturing the entire desktop instead of Roblox and leaking memory
- Fixed unwanted text selection indicators appearing when clicking controls
- Fixed long strategy names and tower lists overlapping the "?" info icon
- Fixed long recordings losing large parts of a strategy. Selling a tower while recording deleted that tower's `SpawnTower` and every `UpgradeTower` step from the recording, so a sell-heavy run could lose roughly half of everything it captured. Selling now only appends the sell and keeps the tower's history
- Fixed tower IDs being reused after a sell, which let a later sell strip the steps of a different tower that happened to share the ID. Tower IDs are now unique for the whole recording, and only deleting a recorded tower frees its ID again
- Fixed saved strategies containing `SellTower(...)` steps for towers that were never placed, which made selling do nothing on replay
- Fixed the recorded strategy being written one file append per step. A long recording now saves in a single write, which is roughly 44 seconds faster for an 8,000 step strategy and cannot leave a half-written file behind
- Added a crash-safe recording autosave. Every recorded action is mirrored to `%AppData%\Ultimate_Macro\recording_autosave.strat` as it happens, so a crash, reload, or cancelled save no longer loses the run. The next recording preserves it as `Recovered_<timestamp>.strat` and says where it went
- Fixed cancelling the save prompt or failing the geometry check silently discarding a finished recording. Both now keep the autosave and say where it is
- Fixed the recording save accepting file names with characters Windows cannot use, which produced an unsaveable path
- Fixed `SellTower` reporting "sold successfully" even when the Sell button was never found or clicked. The sell is now confirmed by the tower panel actually closing, and every failure is logged
- Fixed the Sell button search covering a smaller region than the tower-panel probe, so a panel found near the top of its band could never be sold
- Fixed the modifier search bar falling back to fixed coordinates without saying so
- Fixed the Discord bot's `stop` command making a pointless blocking API request before stopping the macro

## Improved / Changed / Added

- Reworked the overall UI with cleaner spacing, alignment, better colors, and more consistent layouts while keeping the existing design
- Renamed the Record tab to Create and reworked it to include the Record option and a direct Strategy Lab shortcut
- Reworked Settings into one scrollable page instead of a separate Advanced Settings screen
- Moved Legacy Mode next to Potato Mode
- Reworked the Other Tools UI
- Updated the Manage Profiles menu with a dark theme
- Made text boxes, dropdowns, lists, and other controls use the dark theme
- Made dropdown menus match the dark theme when expanded
- Made the Mode selector in the Create page searchable
- Improved spacing and alignment across Settings
- Changed settings to save automatically whenever their values are changed or entered
- Removed the Save All Settings, Party save, and Discord save buttons. All settings now save automatically when changed
- Added a Reset to Default button to Settings
- Removed the Use VIP Server checkbox. VIP server links now work automatically: empty means public server, valid links are used automatically, and invalid links are ignored
- Improved Party input placeholders and updated their example formats
- Added clearer examples for Discord and other input fields
- Removed the Development Contributor section and updated the QA team
- Updated the Ultimate Macro credits with the new development team
- Made the Credits list non-selectable and improved its scrollbar
- Added a button to open the Recordings folder directly from the My Strats page
- Added drag-and-drop support for `.strat` files in My Strats
- Added hover-based info panels for the "?" buttons instead of a Windows notification when clicked
- Renamed `auto_coa` to `auto_ability`
- Removed many unused/dead code after verifying it was no longer needed
- Tools now open in place: clicking a tool opens its window over that tool's preview, hides the preview while the tool is open, and restores it when the tool closes
- Saving a recording now reports how many actions it wrote, both in the log and in the save prompt
- Hotkey labels are shown in a consistent Ctrl / Shift / Alt / Win order regardless of how the key was captured
