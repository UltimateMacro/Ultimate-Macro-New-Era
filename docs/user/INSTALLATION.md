# Installation

## Recommended: official release

1. Open the official Ultimate Macro: New Era GitHub Releases page.
2. Download the asset named `TDS_Macro.zip`.
3. Extract the ZIP completely to a normal folder.
4. Run `Main.ahk`.
5. Configure the macro and Roblox settings before starting a strategy.

Do not run the macro directly from inside the ZIP.

## Why releases are different from source checkouts

Repository source includes tests, validation scripts, GitHub configuration, and development documentation. The official release builder excludes those files and packages only the runtime payload.

If a source checkout is used for development, follow [CONTRIBUTING.md](../../CONTRIBUTING.md) and [TESTING.md](../../TESTING.md).

## Before reporting a problem

Record the Ultimate Macro version, Windows version, display scaling, Roblox client size/window position, affected feature, and reproducible steps.

Never share tokens, webhook URLs, private-server links, or unsanitized personal configuration.
