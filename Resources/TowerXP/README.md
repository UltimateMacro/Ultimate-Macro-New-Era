# Tower XP recognition templates

These PNG files are small, cropped recognition fixtures from the Tower Defense Simulator Triumph reward UI. They were contributed from the Kronox Edition implementation for the optional Tower XP Tracker and are used only to identify default-skin reward cards.

The tracker intentionally ignores alternate skins because they cannot be matched safely against these templates. A missing or uncertain match leaves progression unchanged.
